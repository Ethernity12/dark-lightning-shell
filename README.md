# dark-lightning-shell
Lightweighted cutie dark-themed shell builded using Quickshell, for Hyprland.

## Components
- Login Manager: `SDDM`
- WM: `Hyprland`
- Terminal: `kitty`
- Launcher: `hyprlauncher`
- File Manager: `thunar`
- Shell: `fish`
- Editor: `neovim`
- Widgets: `Quickshell`
- Messanger: `Telegram`
- Browser: `Firefox`

## Themes
- Theme Generator: `pywal`
- Hyprthemes: `hyprtoolkit`

## Fonts
- Asian: `Hina Mincho`
- Cyrillic: `Inter`
- Code: `JetBrainsMono Font`
- Nerd: `JetBrainsMono Nerd Font`

## Utilities
- Wallpaper: `hyprpaper`
- Fetch: `fastfetch`
